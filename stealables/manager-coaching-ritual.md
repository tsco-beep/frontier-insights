# Monday Manager Coaching Ritual Card

**3 coaching hours/month/rep, guaranteed. Free admin calendar + gated AI = no schedule leaks.**

## Who it's for
**Pre-IPO enablement teams (1–3 people) supporting 5–15 frontline managers.**  
If you own coaching cadence but don't control manager calendars, this is your forcing function.

---

## Ritual Checklist

| # | Task | Owner | Frequency | Criteria (Y/N) |
|---|------|-------|-----------|----------------|
| 1 | Create "Coaching Calendar" board in Monday.com | Admin | Once/quarter | Board exists; slots visible to managers |
| 2 | Configure slot gate: max 3 bookings/manager/month | Admin | Once/quarter | AI rejects 4th booking; error message references policy |
| 3 | Block 3 × 1‑hour windows/month in manager calendar | Manager | Monthly | No conflicting meetings; slots marked "Coaching — Hold" |
| 4 | Run 1:1 coaching session (video or in‑person) | Manager | Monthly | Session held; notes logged in CRM/LMS |

---

## Monday Motion (3 steps)

1. **Admin**: Build "Coaching Calendar" board → add slots for current quarter → label each slot with manager name + rep territory.
2. **Admin**: Turn on gated AI rule → set limit to 3 slots/manager/month → test by attempting 4th booking (should fail).
3. **Manager**: Book first coaching window this week → hold the session → log outcome in your tracking system.
