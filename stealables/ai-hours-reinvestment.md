# CRO AI‑Savings Reinvestment Scorecard

**Prove AI bought you time, then prove you spent it on coaching, deals, and selling.**

---

## Who it's for

CROs, Sales Ops, Enablement Leads running 1–3 person teams who want a single-page checklist to turn saved hours into revenue motion — and catch seat‑creep before it starts.

---

## The Scorecard

Copy this table. Fill it weekly. Mark the gap, assign the owner, set the date.

| **Category**       | **AI‑Saved Hours** | **Reinvested Hours** | **Gap** | **Action**                          | **Owner** | **Due** |
|--------------------|--------------------|----------------------|---------|-------------------------------------|-----------|---------|
| Coaching           |                    |                      |         |                                     |           |         |
| Deal Inspection    |                    |                      |         |                                     |           |         |
| Selling Block      |                    |                      |         |                                     |           |         |
| **Total**          |                    |                      |         |                                     |           |         |

**How to fill it:**  
- **AI‑Saved Hours:** Pull from your AI tool's dashboard or ask your ops lead for last week's aggregate.  
- **Reinvested Hours:** Calendar proof — actual hours managers logged in coaching sessions, deal reviews, or selling time.  
- **Gap:** Subtract reinvested from saved. Positive gap = time leaked.  
- **Action:** "Schedule 2 coaching slots" or "Block Friday afternoon for deals."  
- **Owner / Due:** Name + next Monday.

**EXAMPLE**: If AI saved 12 hours (EXAMPLE) and you logged 7 coaching hours, gap = 5 hours. Action: "Add 5 hours of deal‑review blocks by Friday." Owner: Sales Ops. Due: 2025‑05‑09.

---

## Monday Motion (3 Steps)

1. **Pull last week's AI‑saved hours** — export or screengrab from your tool.  
2. **Log reinvested hours** — check calendars, coaching notes, deal‑review agendas. Fill the table.  
3. **Decide on seat purchase**:  
   - **If total gap > 10 hours (EXAMPLE):** Hold the seat request. Fix the leak first.  
   - **If gap ≤ 3 hours (EXAMPLE) for two weeks straight:** Approve the seat.
